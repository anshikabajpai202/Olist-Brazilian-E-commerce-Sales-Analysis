# Olist-Brazilian-E-commerce-Sales-Analysis


## 📌 Project Overview

This project analyzes e-commerce sales data to understand sales performance, product categories, monthly trends, regional performance, order values, customer reviews, and order status.

Python was used for data cleaning, transformation, analysis, and visualization. Power BI was used to create an interactive dashboard.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing product categories
- Analyze monthly sales trends
- Identify high-performing states
- Analyze order value and review scores
- Create an interactive Power BI dashboard
- Generate business insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI

## 🔄 Project Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Data Transformation
5. Sales Analysis
6. Customer & Review Analysis
7. Visualization
8. Power BI Dashboard
9. Business Insights

## 📊 Key Insights

- Total Revenue: **13.59M**
- Total Orders: **98.7K**
- Average Order Value: **137.75**
- Top Category: **Beleza_Saude**
- Best Month: **May**
- Peak May Revenue: **1.50M**
- Best Performing State: **São Paulo (SP)**
- SP Revenue: **5.20M**
- 5-star reviews were the most common rating.

## 📈 Power BI Dashboard

The dashboard includes:

- Revenue by Product Category
- Monthly Sales Trend
- Regional Sales
- Order Value Distribution
- Review Score Distribution
- Category vs Month Heatmap

## 📂 Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**.
Kaggle Dataset Link -  https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The raw dataset is not included in this repository.
